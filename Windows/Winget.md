# Winget Guide

## Purpose

Winget is Microsoft's package manager for Windows.

## Check Winget

```powershell
winget --version
```

## Search

```powershell
winget search supabase
winget search node
winget search python
```

## Install Supabase CLI

```powershell
winget install Supabase.CLI
```

## Notes

Winget may be allowed on business laptops where Scoop or direct downloads are blocked.

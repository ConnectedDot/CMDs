# Windows Command Prompt (CMD) Commands

Below is a categorized list of Windows Command Prompt commands, grouped by their primary usage. This comprehensive list will help you easily refer to and access commands based on their functionality.

---

## 1. **File and Directory Management**
- `dir` - Displays a list of files and subdirectories in a directory.
- `cd` or `chdir` - Changes the current directory.
- `md` or `mkdir` - Creates a new directory.
- `rd` or `rmdir` - Removes a directory.
- `del` or `erase` - Deletes one or more files.
- `copy` - Copies files from one location to another.
- `move` - Moves files from one directory to another.
- `ren` or `rename` - Renames a file or directory.
- `attrib` - Displays or changes file attributes.
- `tree` - Displays a graphical representation of the directory structure.

---

## 2. **System Information and Management**
- `systeminfo` - Displays detailed system information.
- `tasklist` - Displays a list of running processes.
- `taskkill` - Terminates a running process.
- `hostname` - Displays the computer's hostname.
- `ver` - Displays the Windows version.
- `set` - Displays or sets environment variables.
- `echo` - Displays messages or turns command echoing on/off.

---

## 3. **Networking and Internet**
- `ping` - Tests network connectivity to a specific host.
- `ipconfig` - Displays IP configuration information.
- `tracert` - Traces the route packets take to a host.
- `netstat` - Displays network statistics and connections.
- `nslookup` - Queries DNS servers for domain name or IP address information.
- `net` - Manages network resources (e.g., `net use`, `net share`).
- `ftp` - Transfers files to/from an FTP server.

---

## 4. **Disk and Storage Utilities**
- `chkdsk` - Checks a disk for errors and repairs them.
- `diskpart` - Manages disk partitions.
- `format` - Formats a disk for use with Windows.
- `vol` - Displays the volume label and serial number of a disk.
- `label` - Changes or creates a disk label.
- `xcopy` - Copies files and directories, including subdirectories.
- `robocopy` - Robust file copy utility with advanced options.

---

## 5. **User and Security Management**
- `whoami` - Displays the current user.
- `net user` - Manages user accounts.
- `runas` - Runs a program as another user.
- `cacls` - Displays or modifies file access control lists.
- `icacls` - Displays or modifies file and folder permissions.

---

## 6. **System Utilities and Troubleshooting**
- `sfc` - Scans and repairs system files.
- `shutdown` - Shuts down or restarts the computer.
- `bootcfg` - Configures boot settings.
- `bcdedit` - Manages boot configuration data.
- `wmic` - Executes WMI commands.
- `fc` - Compares two files and displays differences.

---

## 7. **Programming and Scripting**
- `for` - Runs a specified command for each file in a set.
- `if` - Performs conditional processing in batch files.
- `setlocal` - Begins localization of environment changes in a batch file.
- `endlocal` - Ends localization of environment changes in a batch file.
- `call` - Calls one batch program from another.
- `pause` - Pauses the execution of a batch file.

---

## 8. **Miscellaneous**
- `cls` - Clears the Command Prompt screen.
- `time` - Displays or sets the system time.
- `date` - Displays or sets the system date.
- `help` - Provides help information for commands.
- `exit` - Exits the Command Prompt.

---

This list is not exhaustive but covers the most commonly used commands. For more details on any command, type `<command> /?` in the Command Prompt.
